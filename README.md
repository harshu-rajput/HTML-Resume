# HTML-Resume
Single-page resume website in HTML


##  About the Project
It's a single-page resume website built using only HTML.  
This project is created as part of the *Web Dev Cohort 2026* assignment to showcase a clear understanding of **HTML structure, semantics, and layout** without using CSS or JavaScript.

The focus is on clean markup, proper sectioning, and readable content flow.
